Clone the repository and open the greenbite-client-server folder in VS Code. Open a terminal from Windows, enter the location of your saved project by using 'ls' and 'cd' (tutorial can be found online) and run:

cd client

npm install

cd ../server

npm install

node server.js

Leave the server running, open a separate terminal and run:

cd greenbite-client-server/client

npm run dev

Open the localhost link shown in the client terminal. To start making your changes, click the branch name in the bottom-left corner and create a branch called [your-name]-changes. Make your changes, open Source Control on the left, enter a message, click Commit and then press Publish Branch once everything in your branch works nicely.

Everytime you make a change, version control should automatically be recording your changes in the left version control sidebar, make sure this is working before spending a load of time programming.

IMPORTANT: Make sure you are working on your named branch. Do not commit or publish changes directly to main. I will review and merge your branch.
